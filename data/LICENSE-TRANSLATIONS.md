# Bundled Public Domain Bible Translations

All four translations bundled in Bible Tabs are in the Public Domain / CC0 and distributed 100% offline:

1. **Berean Standard Bible (BSB)** — Public Domain (CC0 1.0 Universal). Source: https://berean.bible/downloads.htm (`bsb_usj.zip`).
2. **King James Version (KJV)** — Public Domain (1769 Oxford Standard text via eBible.org `eng-kjv2006_usfm.zip`).
3. **World English Bible (WEB)** — Public Domain (No Copyright). Source: eBible.org (`engwebp_usfm.zip`).
4. **American Standard Version (ASV, 1901)** — Public Domain. Source: eBible.org (`eng-asv_usfm.zip`).

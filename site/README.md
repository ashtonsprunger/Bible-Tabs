# Bible Tabs Web Page (`bibletabs.sprungerstudios.app`)

Official landing page, interactive preview, Privacy Policy, Data & Deletion guide, and Support/FAQ subsite for **Bible Tabs** (`ashtonsprunger.bibletabs`) by Sprunger Studios.

## Pages
- `/` — App overview & interactive multi-tab BSB reader preview
- `/privacy-policy.html` (also `/privacy`) — App Store & Google Play Privacy Policy
- `/delete-data.html` (also `/delete-data`) — Local data & deletion instructions
- `/support.html` (also `/support`) — Usage tips, FAQ, and Berean Standard Bible (BSB) CC0 attribution

## Deploy
Run from inside the `site/` directory:
```bash
npx vercel --prod --yes
```
